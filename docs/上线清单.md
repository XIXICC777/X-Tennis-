# 上线前你需要提供的信息与完成的操作

这些是账号或机构负责人才能完成的事项，不是让你重新设计项目。没有这些配置仍可体验独立虚构演示。

## 必须提供的信息（通过对应平台安全配置，不在聊天里发密钥）

- [ ] 微信小程序 AppID，能登录该小程序后台的管理员或开发者身份。
- [ ] 正式云开发环境ID、独立演示环境ID，以及相应服务权限、套餐和预算。
- [ ] 首位管理员在该 AppID 下的微信OPENID，仅在云函数安全环境变量 `BOOTSTRAP_OPENID` 配置；初始化后删除。
- [ ] 机构对外名称、服务类目、实际主体和联系方式、隐私负责人、数据保存期限及紧急联系流程。
- [ ] 规范学校、学年、年级、班级、机构分组清单，现有员工及每名学生的主责和三科分工。
- [ ] 经机构合法收集的必要学生档案、原有监护关系与联系电话；上线前完成监护人告知和必要授权。

不要向我或任何聊天窗口发送AppSecret、腾讯云SecretKey、微信上传私钥、证件照片或真实全量学生表。以后需要自动发布时，在受控密钥配置中输入上传私钥。

## 微信与机构事项，按实际功能核实

- [ ] 在微信后台核实当前教育服务类目和所需主体/资质，不假设这版功能已经满足审核条件。
- [ ] 核实小程序备案、名称使用、认证及当前平台要求，按实际地区和主体办理。
- [ ] 填写正式隐私指引：处理者、采集范围、使用目的、存储/共享、未成年人监护人授权、更正删除和投诉途径。
- [ ] 对相机/相册等实际使用接口完成当前平台要求的隐私声明与授权配置。
- [ ] 依据真实上传内容核实并接入平台要求的内容安全审核；首版仅检查图片格式和大小，不能替代内容安全审核。
- [ ] 如果以后启用订阅消息，先核实可用模板、对应场景、用户主动授权和发送条件，接入成功后单独验收。当前版**不发送主动消息**。

## 技术部署与试用

- [ ] 修改 AppID 和 `config.ts`，编译，部署 `api` 云函数，运行初始化。
- [ ] 正式环境 `DEMO_MODE` 必须为false或缺省，且不存在演示学生数据。
- [ ] 数据库所有业务集合、审计、请求和meta集合拒绝客户端直接读写。
- [ ] 私有存储拒绝客户端直接读取/下载，关闭公开桶和公共文件访问。
- [ ] 按索引清单建立索引，设置兼容的Node16.13及以上云运行时及合理超时（本地构建工具需Node18及以上）。
- [ ] 管理员授权员工，建立学校班级和分工，完成至少两个家长账号的线下核验绑定。
- [ ] 完成真实微信身份、Android/iOS两端、图片、拨号、导出和云并发事务验收。
- [ ] 用普通家长直接请求其他孩子ID、文件ID、导出接口及数据库/存储原生接口，确认全部拒绝。
- [ ] 执行备份恢复演练、记录配额费用与超时监控，确定异常情况下线下联系方式。
- [ ] 删除演示入口依赖，核查正式配置，提交微信审核；审核通过后由你在微信后台发布。

首版不包含收费商城、营销裂变、排行榜、直播、人脸识别、即时聊天或AI批改。云发布需要你的平台身份，由本地自动化测试通过不能替代。
