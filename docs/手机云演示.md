# 手机连接微信云演示：当前环境操作单

客户端已配置为 `mode: 'cloud'`、环境ID `cx100-d3ga3i1ljcfc054ca`，并附带编译JS。该ID不是AppID，也不是密钥。云端是否已开通、部署和初始化尚未由开发环境验证。

## 一、下载并导入

1. 下载当前版本到一个新文件夹，保留旧项目及其本地配置。
2. 在微信开发者工具导入包含 `project.config.json` 的目录，填写你刚注册的真实小程序AppID。仓库配置仍是测试AppID，导入时必须替换为自己的账号。
3. 本地修改TS后执行 `npm ci`、`npm run build`；下载版已有完整JS。手机云模式不需要运行 `npm run demo`，该命令只启动电脑本地的虚构演示服务器，不会把客户端切回本地模式。

## 二、上传云函数

1. 打开“云开发”，选择环境ID为 `cx100-d3ga3i1ljcfc054ca` 的环境。
2. 回到项目文件树，展开 `cloudfunctions`。对 `api` 文件夹右键，若提示关联环境，选择同一环境。
3. 选择“上传并部署：云端安装依赖”，等待上传和依赖安装完成。
4. 打开云开发控制台的“云函数”，应能看到 `api`。配置支持Node.js 18及以上的运行时、至少256MB内存和60秒超时；保存后确认生效。

## 三、开启虚构演示并初始化

只有此环境专用于虚构演示时才按本节操作，勿将真实学生信息录入此环境。正式环境应另建，遵循部署说明中的首位管理员流程。

1. 云函数列表中打开 `api` 的配置页面，找到“环境变量”，添加：

   | 名称 | 值 |
   |---|---|
   | DEMO_MODE | true |

2. 保存，确认配置生效。若控制台提示需重新部署，按提示完成。不要只在电脑终端设置这个变量。
3. 在**云函数控制台**打开 `api` 的“测试”，输入：

   ```json
   {"action":"initialize"}
   ```

4. 执行。应返回 `ok: true` 及“初始化完成”的消息，并在数据库中出现 `zimo_demo_` 前缀的集合。此操作不能通过小程序客户端调用。
5. 如果返回 `ok: false`，先保留完整返回结果，核实变量是否生效、运行时及云端安装依赖是否完成，不要反复更换环境或放宽权限。

## 四、数据库与私有文件权限

1. 所有 `zimo_demo_*` 集合（含users、files、requests、audit、meta）的客户端权限设为仅管理端读写，对应自定义规则为：

   ```json
   {"read":false,"write":false}
   ```

2. 云存储同样设为仅管理端读写；不创建公开文件桶或公共下载入口。云函数通过受信任服务端SDK访问。
3. 按 `docs/indexes.json` 为 `zimo_demo_` 集合建立索引，等待构建完成。该清单包括日期、学生归属、监护绑定等查询。
4. 权限和索引设置应先完成，再进行完整功能验证。当前开发者不能代替你核验实际控制台设置。

## 五、手机预览

1. 回到开发者工具，确认当前项目是新版本、真实AppID，且构建后 `miniprogram/config.js` 显示云模式及上面的环境ID。
2. “清缓存 → 全部清除”，重新编译。正常应出现黄色“虚构演示”提示及演示孩子。
3. 用开发者微信扫描“预览”二维码，在手机测试。其他体验人员应按微信后台要求添加体验成员并使用体验版；这不等于正式发布。
4. 依次测试孩子切换、老师保存、家长刷新、作业、反馈、图片鉴权。云数据保存在云端，电脑不必保持本地演示服务器运行。
5. 若仍提示“请先运行npm run demo”，手机仍在运行本地模式旧包；核对导入目录和config.js，清缓存后重新生成二维码扫码。
6. 若改为“操作失败，请检查云环境配置”，说明已切到云调用；继续检查 `api` 部署、同一环境、环境变量、初始化、索引和权限，提供对应报错继续排查。

真机和微信云数据库/文件存储验收尚待这次实际操作。演示环境不能作为正式运营环境，也没有完成微信审核发布。
