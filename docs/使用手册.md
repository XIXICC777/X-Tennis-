# 子墨学堂分步骤使用手册

## 先认清当前模式

页面顶部有黄色“虚构演示”条：里面的孩子、学校、老师、家长、成绩全部是编造的，任何保存都只用于体验。正式环境不提供演示身份切换。

本地演示账号不使用密码。在黄色条选择身份：

| 身份 | 可以体验什么 |
|---|---|
| 管理员 / 主责老师（周老师） | 全部管理、三科记录、主责反馈和核验 |
| 数学老师（林老师） | 查看学生三科情况，处理分配给自己的数学任务；不能发布别人的主责反馈 |
| 小禾与小宁家长 | 切换两个已核验孩子，只能读取这两个孩子 |
| 小川家长 | 只能查看小川，不可查看小禾 |

种子包含两个学校、两个年级、三个学校班级、两个机构分组、四名学生，以及英语“请假补做”个人例外。小禾的成绩曲线是虚构样例，小川暂无成绩，界面不会用零分代替。

## 管理员第一次使用

1. “机构管理” → “新增学校”：填写规范学校名称。
2. “新增学校班级”：选学校，输入班级名、年级1—6、学年起始年份，例如2026表示2026学年。
3. “新增机构分组”：例如“周一至周五16点组”。这个分组不替代学校班级。
4. 老师先登录并设置称呼，复制页面上“我的账号编号”给你。点“授权已登录员工”，填写编号与职责；授权后让老师刷新。
5. “新增学生”：填写学生编号和姓名，选择学校班级、机构分组、主责老师以及语数英负责老师。同一老师可以兼任多科和主责。
6. 切换到“学生档案”检查资料。升年级时先建立新学年班级，再点“编辑档案 / 升级转班”，只改当前班级。历史作业、成绩仍保留旧班级快照。
7. 员工离职时点对应老师“修改职责 / 停用”，关闭启用开关。调整学生分工与主责归属，避免留下无人负责的学生。

## 每天老师怎么做

1. 看顶部日期是否正确，必要时筛选学校、年级、班级、科目或主责老师。
2. 选孩子 → “记录到店 / 离店 / 请假”。已到店和已离店分别记录时间，未记录不会推测成已经到店。
3. “同班作业”：点学生条目勾选孩子；也可“选择今天已到店学生”。一次发布必须是同一学校班级，混选会被服务器拒绝。
4. “新增共同作业并分发”：核对日期、班级、科目，写一次内容及来源；只有明确核实时才打开“已核实来源”。来源不明确会显示“待核实”。
5. 想复用上一份内容：把顶部日期切到旧作业日期，选中目标孩子，点“复制后修改发布”，再在表中改成新日期。复制不会复制旧学生的完成记录。
6. “今日工作台”选孩子，点任务下方“记录进度 / 检查 / 复核”：通常依次是未开始 → 进行中 → 待检查 → 检查通过，或待检查 → 订正中 → 订正已复核。核实待核实来源时同样需要明确确认。
7. 孩子说写完了只选“待检查”。你亲自检查或复核后才选择对应状态并打开“我已亲自检查／复核或核实来源”。系统不会把整班自动标成检查通过。
8. 需要帮助用单独开关；请假补做、分层作业、免做、个人订正或事先约定的家庭加练，用“个人例外”并写必要说明。
9. 要改共同内容，点“修改共同内容”。确认框显示受影响人数；服务器保留每名孩子原进度，旧共同内容进入修订历史。
10. 保存成功才会提示“保存成功”。失败会保留表单；原地重试。若提示记录已经更新，关闭表单、刷新后核对最新版本再录入。

待办区汇总待检查、需要讲解、待复核、遗留、到期错题和家长沟通。到期错题跨天仍存在，需要复查结果或显式改期才改变待办。

## 重点错题与具体进步

1. 选孩子 → “反馈与跟进” → “重点错题”。只记值得跟进的典型问题。
2. 填题目位置、知识点、错误表现、已采取帮助、同类题当日验证结果和下次复查日期。原题订正不自动等于同类题独立通过。
3. 如果要配图，先选科目，再点“上传题目照片”；仅JPEG/PNG，≤500KB。上传成功会自动填入附件编号，再保存卡片。不要拍到无关孩子或无关个人信息。
4. 到期点“记录复查”，填写实际结果和事实说明；继续跟进须填下一次日期，仍需支持不能直接结束。
5. 有前后两条复查记录时，主责老师可以添加“具体进步”，选择前后证据，比如“之前需要完整提示，现在能独立列式”。不能用系统分数代替事实证据。

## 主责老师的周目标、交接与日报

1. 每周给孩子设一个具体可观察的目标；结束日期必须在当周内。同一周再次保存会更新该周目标，不增加第二个并行目标。
2. 未做完的事点“遗留交接”，写什么未完成、原因、下一步、负责人及期限；处理后记录结果，不会到期自动消失。
3. 情绪和学习状态点“状态支持”，写观察事实、已经提供的帮助和后续情况。内部详细记录只有分配老师等授权员工能读取，不会自动拼进家长反馈。供家长参考的说明也须由主责老师审阅后写进日报。
4. 点“汇总日报草稿”或“汇总近7日周反馈”。系统仅从已有任务、进步证据、未完成交接汇总；没有记录会明确写“尚无记录”。
5. 打开草稿“编辑并确认发布”，补充具体收获、必要状态说明及家庭配合。核对事实后确认发布。草稿家长看不到，发布后不可被再次生成草稿覆盖。
6. 家长点“需要沟通”后会形成待办，主责老师记录处理结果。第一版不提供聊天对话，也没有主动订阅推送；不能等待通知一定送达。
7. 重要异常进入“学生档案”→“联系已核验监护人”，选联系人拨号。如果尚无绑定，请使用机构已有的线下紧急联系流程。

## 如何绑定家长

1. 主责老师选择孩子 → “学生档案” → “生成24小时一次性邀请”。复制发送给已经确认身份的监护人。
2. 家长进入小程序，点击“输入邀请并申请绑定”，填邀请码、关系及联系电话。**申请成功不等于绑定生效**。
3. 老师在孩子档案看到申请；按原留联系方式、当面等方式核验，不要只凭名字或邀请码判断。
4. 点“机构核验”，写核验依据（不录证件号码），打开核验通过开关并确认。
5. 家长刷新后看到孩子；多个孩子分别申请，同一孩子可邀请多位监护人。
6. 关系变更时主责老师撤销绑定，再核验新申请。已保存截图和导出不能从对方设备远程收回。

## 家长每天怎么看

1. 先在顶部孩子卡切换；下面首先显示到店／离店，再显示当天三科任务和更新时间。
2. 往下看已发布反馈、本周目标、重点问题卡和成绩曲线。详细反馈尚未发布时有明确提示，不把空白当作孩子没完成。
3. 成绩可以选科目、考试类型、开始和结束日期。折线纵轴是得分／满分的百分比，横轴是日期，换算不代表难度一致。点节点或列表看原始分数、满分、来源、核验状态及备注。
4. 历史日报、周反馈和复查记录在下方；也可从“反馈与跟进”查看完整列表。
5. 点“标记已阅”记录阅读；需要进一步沟通时填写问题，机构主责老师处理。
6. 下拉或点“刷新记录”获取最新保存数据。本版没有实时推送或自动轮询，顶部显示的是本次获取时间，各任务另有实际修改时间。

## 成绩录入和导出

- 老师选孩子 → “成绩记录” → “录入考试成绩”；填写日期、名称、类型、原始得分、满分、范围、来源、核验和备注。
- 尚未获得分数就不要录入；空分数不能当零分，真实零分可以明确录入0。
- 当前首版考试记录新增后保持原记录，错误成绩由管理员在受控控制台更正并登记原因；界面暂不提供成绩删除／编辑。
- 员工在“学生档案”可“导出该孩子的JSON记录”；家长在首页底部点“导出孩子学习记录（JSON）”，自动过滤内部记录。
- 文件只包含当前操作者被授权看到的该学生数据，导出不是全库备份；全库备份见架构文档。
