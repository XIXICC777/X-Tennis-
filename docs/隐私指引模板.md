# 隐私指引填写模板（上线前由机构补齐并审阅）

当前页面提供原则说明，本文件不是已完成的法律合规结论。请把占位信息替换为真实机构信息，并在微信后台完成对应指引。

1. **处理者和联系方式**：填写机构主体全称、服务地址、隐私联系人、联系电话、工作时间及投诉渠道。
2. **学生与监护信息**：学生编号、姓名、学校年级班级、机构分组、教学分工及在读状态用于开展辅导；监护关系和电话用于核验、反馈与必要联络，不收集身份证号和无关家庭资料。
3. **学习记录**：共同作业、个人进度、典型错题及题目照片、复查、成绩及来源、已发布反馈、家长沟通用于辅导和反馈。拍照前应避免无关儿童、姓名册和敏感资料出现在照片中。
4. **必要状态事实**：仅记录可观察事实、已采取支持及后续，不诊断、不打心理分，不使用污名标签。内部记录不直接提供给家长端；老师须审阅外部说明。
5. **身份与访问**：微信身份用于关联账号；家长须持有限期邀请申请并经机构核验，只能查看所绑定孩子；员工按学科和主责权限操作。
6. **设备权限**：只在主动上传题目照片时按微信当前要求使用相册/相机；主动点联系入口才发起拨号，主动导出才生成文件。拒绝非必要设备权限不应阻止文字作业记录和查看。
7. **存储与期限**：填写真实云服务提供者、存储地区、教学记录保留期限、退读后的保留/删除规则、审计保留期限和备份到期策略；不得默认永久保存。
8. **提供与分享**：由机构授权的老师、已核验监护人和必要云服务商按目的处理，不用于广告或营销；获授权导出的文件和截图需由接收人妥善保管。
9. **更正、导出和删除**：填写具体申请入口、核验方式、办理期限及联系负责人。首版提供单学生授权导出；全量删除由管理员在维护窗口核实后执行，同时处理绑定、关联记录、文件、审计保留依据和到期备份。
10. **儿童个人信息**：面向6—12岁儿童，须取得所需监护人同意，解释采集用途和撤回方式。监护关系变更应撤销旧绑定并重新核验。
11. **通知**：主动查看与主动推送分开。第一版不发送订阅消息；以后启用需单独解释模板、授权及无法保证到达的情形。重要异常按机构紧急联系流程处理。
12. **更新**：填写指引生效日期、版本和重大变更的告知方式。
