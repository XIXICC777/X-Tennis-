# 第一版实现与验收报告

本报告区分本机自动化验证和真实微信云验收，不把演示数据当成上线数据。

## 已实现

- 原生小程序中文工作台；老师、家长、管理员按身份展示；主责职责可由现有老师兼任。
- 学校、学年、规范学校班级、机构分组、学生编号、主责、三科分工、员工授权与停用，转班保留历史快照。
- 同班一次录入多人分发、到店选择、旧作业复制、个人例外、共同内容修订历史。
- 三科独立任务、帮助独立标记、检查/复核显式确认、到离店时间及持续待办。
- 典型错题卡、私有图片接口、同类题验证与后续复查、到期逾期保留。
- 成绩录入、科目/日期/类型筛选、百分比折线与原始分数列表、节点详情、来源/核验标注，缺失不补零。
- 真实记录汇总日报/周反馈草稿、主责编辑确认发布、已阅和家长沟通待办。
- 一个当前周目标、有前后复查证据的具体变化、遗留交接和结果、内部状态事实与外部说明分开。
- 限期一次性邀请、机构核验、多个孩子/监护人、撤销绑定；服务端拒绝越权读写/图片/导出。
- 请求重试去重、同内容重复发布去重、版本冲突、关键审计、事务缓冲及失败回滚。
- 独立虚构演示服务及持久化；云开发数据库/函数/文件存储适配；部署、索引、权限、隐私和备份恢复说明。

## 实际运行

开发环境：Linux，Node.js 24.19.0，TypeScript 5.9.3；小程序类型包4.0.8，云函数SDK3.0.1，官方维护的miniprogram-compiler0.2.3。

- `npm run typecheck`：通过。
- `npm test`：**29项通过，0失败，0跳过**（包含构建、业务、客户端、云适配器、HTTP及模板测试）。
- WXML/WXSS编译：通过；家长工作台使用实际业务服务结果生成虚拟节点，确认不渲染内部状态/管理操作；缺失科目明确待核实。
- 实际独立服务启动和HTTP：通过，管理员看到4位虚构学生，家长只看到已核验孩子；其他孩子请求返回FORBIDDEN。
- HTTP独立集成测试：启动随机端口，实际发布共同作业、老师更新、家长鉴权与文件读取，停服重启后记录及私有字节仍可按权限读取。
- 云SDK事务适配测试使用受控数据库替身，验证单文档事务、修订锁、缓冲可见性和异常回滚；**不是已连接真实云数据库的证明**。

## 你要求的12个场景

| 场景 | 已执行结果 |
|---|---|
| 1. 同班录入一次多人分发 | 共同记录1条，个人任务2条，通过 |
| 2. 个人修改不影响其他人 | 深比较另一孩子记录不变，通过 |
| 3. 共同修订保留个人进度 | 个人记录完全不变，旧版本保留，通过 |
| 4. 三科同时操作 | Promise.all并发调用，三份结果保留；过期同科版本被拒绝，通过（真实云并发待验） |
| 5. 篡改孩子/接口/图片越权 | 学生、导出、任务、角色、图片读均拒绝，文件存储读取未被调用，通过（真实存储规则待验） |
| 6. 写完尚未检查 | 仅待检查，无确认者；跳级被拒绝，通过 |
| 7. 订正未复核 | 无confirm不能进入已复核；显式复核记录操作者，通过 |
| 8. 到期和逾期持续待办 | 当日与未来查询均存在，显式复查改期后改变待办，通过 |
| 9. 真实汇总确认发布 | 草稿内容关联真实任务ID、家长不可见、非主责被拒绝、确认发布后可见，通过 |
| 10. 缺失成绩不计零 | 无成绩返回空数组，非法分数拒绝；客户端空分数阻止保存，通过 |
| 11. 重复发布及重试 | 并发同请求幂等，新请求相同内容不新增任务且不清空进度，通过 |
| 12. 保存失败明确提示 | 原表单保留、无成功提示、错误可见、重试沿用编号；批量失败回滚，通过 |

额外覆盖：邀请到期、一次性与待核验隔离、核验/撤销权限变化、学科权限、情绪导出隔离、转班快照、停用即拒绝、同周一个目标、演示磁盘写失败不提交内存。

## 未实现或尚未验证

- **未在真实微信云环境部署**：无AppID、云ID和微信身份，云端集合/索引/事务行为、真实存储拒绝规则、配额费用及冷启动尚待验证。
- **未在微信开发者工具模拟器或真机运行**：当前为Linux命令行，已做TS与官方封装模板编译/节点渲染；相机/相册授权、隐私弹窗、图表触摸、文件分享与拨号仍须实机联调。
- 官方网站访问被当前网络策略拒绝；无法声称已核对当前全部平台规则。部署说明附官方入口，由实际账号按现行控制台核实。
- 订阅消息发送、完整即时聊天、独立电脑后台、AI评语/批改不在首版。反馈在小程序内保留，重要异常用拨号入口。
- 未接入生产图片内容安全审核；格式头检查不替代审核。未完成主体资质/备案/隐私正式审核。
- 未做真实云压力与长期历史数据测试。一次匹配查询上限10000条；每页100条。表修订锁保护查询一致性，但高并发会有重试和吞吐限制。
- 图片≤500KB，未提供自动裁剪/压缩编辑；表单取消可能留下私有孤立文件，需管理员维护清理。
- 不提供UI成绩修改/删除、学校及分组删除、已发布反馈撤回重发、自动升年级、自动备份调度和自助全量删除。更正由受控管理员维护并留记录，扩展前不可直接删历史数据。
- 周反馈以近7天记录为结构化草稿，反复问题频率及下周重点须老师核对填写；不会自动推断掌握或进步结论。
- 家长已下载的文件或截图无法远程撤回；未实现浏览器外部管理后台的认证。

## 真实云联调检查单

1. 两个真实家长分别绑定不同孩子；尝试交换studentId、taskId、fileId和export参数，全部越权拒绝。
2. 使用普通家长身份直接读集合或下载云存储fileID，必须被平台规则拒绝；授权fileRead则成功，撤销绑定后立即拒绝。
3. 两名老师同时更新不同科，重新读取均存在；同一任务旧版本报冲突，不覆盖。
4. 云函数冷启动、数据库写入失败、弱网/断网时显示失败；重复重试不新增任务。
5. 图片上传、取消授权、超限图片、两种图片格式的预览，在Android和iOS均验收。
6. 成绩图点选、原始分数与满分、范围/考试类型过滤、JSON导出和拨号验收。
7. 发布前家长看不到草稿；主责发布后家长刷新可见；已阅、沟通与内部情绪隔离验证。
8. 独立环境执行数据库和存储备份恢复演练，核对引用与权限后才正式切换。
